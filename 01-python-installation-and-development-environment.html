1. Development environment kya hota hai?

Development environment woh setup hota hai jahan programmer code likhta, save karta, run karta aur errors check karta hai. Is setup mein aam tor par programming language, interpreter, code editor, terminal aur project folders shamil hotay hain.

Agar aap Python seekhna chahti hain, to sirf Python install karna enough nahi. Aapko yeh bhi samajhna hoga ke code kahan likhna hai, file kis naam se save karni hai, terminal se program kaise run karna hai, aur error aaye to usay kaise read karna hai.

2. Python interpreter kya karta hai?

Python interpreter woh software component hai jo Python instructions ko run karne mein help karta hai. Jab aap likhti hain: 

print("Hello Python")

to interpreter is instruction ko process karta hai aur screen par output show hota hai: 

Hello Python

Simple terms mein, aap code likhti hain aur interpreter us code ko execute karne ka kaam karta hai.

3. Python kahan se install karni chahiye?

Python hamesha trusted official source se install karni chahiye. Random websites se installer download karna unnecessary risk hai. Official Python website ka address hai:

https://www.python.org/

Website par Downloads section mein ja kar apne operating system ke mutabiq installer choose kiya jata hai. Windows users ke liye Windows installer available hota hai.

Security reminder: Python installer sirf official Python website se download karein. Unknown websites, cracked packages aur suspicious “one-click Python installers” se door rahna behtar hai.

4. Windows par Python installation: step by step

Step 1: Installer download karein

  1. Browser open karein.
  2. Official Python website par jayein.
  3. Downloads section open karein.
  4. Windows ke liye suitable Python 3 installer download karein.

Step 2: Installer run karein

Downloaded installer ko open karein. Installation window mein options carefully read karein. Sab se important option aam tor par yeh hota hai: 

Add python.exe to PATH

Agar yeh option available ho, to isay select karna useful hota hai. Is se Windows terminal ko Python command locate karne mein asani hoti hai.

Step 3: Install Now

Basic beginner setup ke liye Install Now option use kiya ja sakta hai. Installation complete hone ka wait karein. Agar Windows security permission maange, to sirf trusted official installer ke liye appropriate permission dein.

Step 4: Installation complete hone dein

Installation complete hone ke baad success message show ho sakta hai. Ab terminal ko close karke dobara open karna useful hota hai, taa-ke updated PATH settings apply ho sakein.

5. Python installation verify karna

Installation ke baad Windows mein Command Prompt ya PowerShell open karein. Phir yeh command type karein: 

python --version

Agar Python properly install hai, to output kuch is type ka ho sakta hai: 

Python 3.x.x

Yahan 3.x.x ka matlab installed Python 3 version hai. Exact version aapke installed release par depend karega.

Alternative command

Kuch Windows systems par Python launcher ke liye yeh command bhi work karti hai: 

py --version

Agar python --version work na kare, to py --version try karein.

6. Python interactive shell kya hota hai?

Python install hone ke baad terminal mein sirf python likhne se interactive shell open ho sakta hai. Isay REPL bhi kaha jata hai. REPL ka meaning hai:

  • Read: Aapki instruction read karna.
  • Evaluate: Instruction ko process karna.
  • Print: Result show karna.
  • Loop: Dobara next instruction ka wait karna.

Example:

python

Phir Python prompt par:

2 + 3

Output:

5

Interactive shell chhoti experiments ke liye useful hai. Lekin complete projects ke liye hum aam tor par .py files use karenge.

Interactive shell se exit kaise karein?

  • Windows par exit() likh kar Enter press karein.
  • Keyboard shortcut Ctrl + Z, phir Enter bhi Windows par use ho sakta hai.

7. Python file kya hoti hai?

Python code ko file mein save karne ke liye normally .py extension use hoti hai. Misal ke taur par:

  • hello.py
  • salary_calculator.py
  • employee_management.py

File ka naam meaningful rakhna chahiye. Spaces se bachna aur lowercase plus underscores use karna beginner-friendly convention hai, jaise salary_report.py.

8. Pehli Python file banana

Ab ek simple file banate hain.

  1. Desktop par ek folder banayein: PythonPractice.
  2. Is folder ke andar ek new text file banayein.
  3. File ka naam hello.py rakhein.
  4. File mein yeh code likhein:
print("Assalam-o-Alaikum!")
print("Mera pehla Python program hai.")
print("Main Python seekh rahi hoon.")
Important Windows point: Kabhi kabhi Windows file extensions hide karta hai. Aisi situation mein file ka naam ghalti se hello.py.txt ban sakta hai. File Explorer mein “File name extensions” enable karke extension verify karein.

9. Python file ko terminal se run karna

Ab Command Prompt ya PowerShell open karein. Sab se pehle us folder mein jayein jahan file save hai. Agar folder Desktop par hai, to command kuch is type ki ho sakti hai: 

cd Desktop\PythonPractice

Yahan cd ka matlab hai change directory. Is command se terminal ka current folder change hota hai.

Ab file run karein:

python hello.py

Agar Python launcher use karna ho:

py hello.py

Expected output:

Assalam-o-Alaikum!
Mera pehla Python program hai.
Main Python seekh rahi hoon.

10. Working directory kya hoti hai?

Working directory woh folder hota hai jahan terminal is waqt kaam kar raha hota hai. Agar aap hello.py run kar rahi hain aur terminal kisi doosre folder mein hai, to Python file find nahi kar payega jab tak aap correct folder mein na jayein ya file ka complete path provide na karein.

Current directory dekhne ke liye Windows Command Prompt mein:

cd

Folder ki files dekhne ke liye:

dir

Yeh commands terminal navigation ke basic tools hain. Aage chal kar projects ke saath kaam karte waqt yeh bohat useful hongi.

11. Code editor kya hota hai?

Code editor woh application hai jahan aap code likhti hain. Simple Notepad bhi text likh sakta hai, lekin programming ke liye specialized editor zyada useful hota hai kyun ke woh syntax highlighting, auto-completion, indentation aur error hints provide kar sakta hai.

12. IDLE ka basic use

IDLE Python ke saath available basic development environment hai. Is mein Python Shell aur editor dono mil sakte hain.

  1. Start Menu mein IDLE search karein.
  2. IDLE open karein.
  3. File menu se New File choose karein.
  4. Code likhein.
  5. File ko hello.py ke naam se save karein.
  6. Run menu se Run Module choose karein.

IDLE simple exercises aur early lessons ke liye enough ho sakta hai.

14. PATH kya hota hai?

PATH operating system ka ek environment setting concept hai. Is mein folders ki locations hoti hain jahan system executable commands search kar sakta hai.

Agar Python ka path properly configured ho, to aap terminal mein directly: 

python

likh kar Python run kar sakti hain. Agar PATH configured na ho, to system keh sakta hai ke “python is not recognized” ya similar error aa sakta hai.

Beginner ke liye important point: installation ke waqt Add Python to PATH select karna future command-line work ko easy bana sakta hai.

15. Common errors aur unke solutions

Error 1: “python is not recognized”

Possible reasons:

  • Python install nahi hui.
  • PATH option select nahi hua.
  • Terminal installation se pehle open tha.
  • System mein Python command ka alternate launcher use hota hai.

Try:

py --version

Agar yeh work kare, to aap py hello.py use kar sakti hain. Warna Python installation aur PATH settings verify karein.

Error 2: “can't open file”

Is ka matlab ho sakta hai ke terminal current folder mein woh file nahi mil rahi. dir se files check karein aur cd se correct folder mein jayein.

Error 3: File actually .txt hai

Agar file ka naam hello.py.txt hai, to Python usay expected Python file ke taur par handle nahi karega. File extensions visible karke name correct karein.

Error 4: Syntax error

Agar code mein spelling, brackets, quotes ya punctuation ghalat ho, to Python error show kar sakti hai. Error message ki line number ko dekhein aur us line ko carefully inspect karein.
