1. Program ki basic anatomy

Python program instructions ka collection hota hai. Har line koi action perform kar sakti hai, jaise text show karna, calculation karna, value save karna ya decision lena.

Sab se simple Python instruction:

print("Hello, Python!")

Is line ko teen parts mein samajhein:

PartMeaning
printPython ka built-in function jo output display karta hai.
( )Parentheses, jin ke andar function ko values di jati hain.
"Hello, Python!"String value, yani text.

2. print() kya karta hai?

print() Python ka built-in function hai jo given values ko standard output, aam tor par screen ya terminal, par display karta hai. 

print("Assalam-o-Alaikum!")

Output:

Assalam-o-Alaikum!

Function ko call karna ka matlab hai us function ko execute karne ke liye use karna. Yahan hum print() ko call kar rahe hain.

3. Text print karna: strings

Text ko Python mein aam tor par string kaha jata hai. String ko single quotes ya double quotes mein likh sakte hain. 

print("Hello")
print('Hello')
print("Python seekhna interesting hai")
print('Python seekhna interesting hai')

Single aur double quotes dono valid hain. Beginner ke liye important baat yeh hai ke opening aur closing quotes match honi chahiye.

Ghalat example: 
print("Hello')
Yahan opening double quote hai aur closing single quote. Quotes match nahi kar rahe, is liye syntax error aa sakta hai.

4. Numbers print karna

Numbers ko quotes ke baghair bhi print kiya ja sakta hai. Quotes lagane se number text ban jata hai. 

print(25)
print(100)
print(75.5)

Output:

25
100
75.5

Number aur text mein difference

print(25)
print("25")

Dono ka output screen par 25 nazar aa sakta hai, lekin pehli value number hai aur doosri string hai. Aage calculations mein yeh difference bohat important hoga.

5. Multiple values print karna

Aap print() ko comma se separate karke multiple values de sakti hain. 

print("Name:", "Ayesha")
print("Age:", 22)
print("Salary:", 85000)

Output:

Name: Ayesha
Age: 22
Salary: 85000

Default tor par comma-separated values ke darmiyan ek space add hota hai. Is default behavior ko baad mein sep parameter se change bhi kiya ja sakta hai.

6. sep parameter

sep ka matlab separator hai. Yeh batata hai ke multiple values ke darmiyan kya place kiya jaye. 

print("2026", "09", "14", sep="-")

Output:

2026-09-14

Ek aur example:

print("A", "B", "C", sep=" | ")

Output:

A | B | C

7. end parameter

Normally print() ke baad cursor next line par chala jata hai. end parameter se aap decide kar sakti hain ke output ke end par kya add ho. 

print("Hello", end=" ")
print("World")

Output:

Hello World

Agar end="" use karein, to next print same line par continue hoga: 

print("Python", end="")
print("Course")

Output:

PythonCourse

8. Escape sequences ka basic idea

Escape sequence special character combinations hoti hain jo strings ke andar special formatting ke liye use hoti hain.

SequenceMeaningExample
\nNew lineprint("A\nB")
\tTab spaceprint("A\tB")
\\Backslashprint("C:\\Python")
\"Double quote inside double-quoted stringprint("He said \"Hi\"")
\'Single quote inside single-quoted stringprint('It\\'s okay')

New line example

print("First line\nSecond line\nThird line")

Output:

First line
Second line
Third line

9. Comments kya hotay hain?

Comment code ke andar programmer ki explanation ya note hota hai jo normal execution mein Python ignore kar deti hai. Comments ka purpose code ko samajhna, maintain karna aur future mein yaad rakhna easy banana hai.

Single-line comment

# Yeh ek comment hai
print("Hello Python")

Hash symbol # ke baad us line ka text comment ban jata hai. Python usay instruction ke taur par execute nahi karti.

Inline comment

print("Hello")  # Screen par greeting show karna

Inline comment code ke same line par bhi likha ja sakta hai. Lekin comment ko itna lamba na banayein ke actual code samajhna mushkil ho jaye.

10. Comments kyun use karte hain?

  • Complex logic ko explain karne ke liye.
  • Future self ko context yaad dilane ke liye.
  • Team members ko code samajhne mein help karne ke liye.
  • Temporary testing ke waqt kisi line ko disable karne ke liye.
  • Important assumptions aur business rules note karne ke liye.
Good practice: Har line par obvious comment likhna zaroori nahi. Comment tab likhein jab logic, reason ya business rule immediately obvious na ho.

11. Comment se code temporarily disable karna

print("Line 1")
# print("Line 2")
print("Line 3")

Output mein sirf Line 1 aur Line 3 show hongi. Line 2 comment ban chuki hai, is liye execute nahi hogi. Is technique ko kabhi kabhi “commenting out” kehte hain.

12. Indentation kya hoti hai?

Indentation line ke start par spaces ya tabs ka use hai. Python indentation ko code blocks define karne ke liye use karti hai. Doosri languages mein curly braces { } common hoti hain, lekin Python mein indentation syntax ka important part hai.

Example:

if True:
    print("Yeh indented line hai")

Yahan if True: ke baad wali line 4 spaces se indented hai. Is se Python samajhti hai ke print() statement if block ka hissa hai.

13. Indentation ke basic rules

  • Block start karne wali line ke end par aam tor par colon : hota hai.
  • Block ke andar wali lines same indentation level par honi chahiye.
  • Python community mein 4 spaces common convention hai.
  • Tabs aur spaces ko randomly mix nahi karna chahiye.
  • Indentation ghalat ho to IndentationError ya TabError aa sakta hai.

Correct indentation

if True:
    print("First statement")
    print("Second statement")

Incorrect indentation

if True:
print("This may cause an error")

Block ke andar statement indented honi chahiye. Sirf visual alignment nahi, Python ke syntax ke liye bhi indentation important hai.

14. Nested indentation

Kabhi ek block ke andar doosra block hota hai. Isay nested block kehte hain. Har next level par indentation barh jati hai. 

if True:
    print("Outer block")

    if True:
        print("Inner block")

    print("Back to outer block")

Is example mein inner if aur uska print() outer block ke andar hain, lekin inner print ki indentation zyada hai.

15. Blank lines aur readability

Blank lines program ko readable banati hain. Python aksar blank lines ko ignore karti hai, lekin humans ke liye yeh code ko sections mein divide karne mein help karti hain. 

print("Employee details")

print("Name: Ayesha")
print("Department: Finance")

print("Salary details")
print("Basic salary: 80000")

Related statements ko group karna aur sections ke darmiyan blank line rakhna clean code ki achi habit hai.

16. Multi-line first program

Ab hum ek chhota program banate hain jo employee ki basic information display karega. 

# Employee ki basic information display karna

print("===== Employee Information =====")
print("Name:", "Ayesha")
print("Department:", "Finance")
print("Basic Salary:", 80000)
print("Status:", "Active")
print("================================")

Is program mein comments, strings, numbers aur multiple print() statements use huay hain. Abhi hum data ko manually likh rahe hain. Agle lessons mein variables ki madad se values ko reusable banayenge.

17. Common mistakes

Mistake 1: Parentheses miss karna

print "Hello"

Modern Python 3 mein function call ke liye parentheses required hain: 

print("Hello")

Mistake 2: Quotes close na karna

print("Hello)

Correct:

print("Hello")

Mistake 3: Case sensitivity ignore karna

Print("Hello")

Python case-sensitive hai. print aur Print same nahi hain.

Mistake 4: Indentation ghalat karna

if True:
print("Hello")

Block ke andar statement indent honi chahiye.

Mistake 5: Number ko unnecessary quotes dena

print("80000")

Yeh output ke liye valid hai, lekin value string hai. Future calculations mein actual number aur string ka difference matter karega.
